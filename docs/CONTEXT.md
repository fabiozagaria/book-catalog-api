# Contesto tecnico — Book Catalog API

Aggiornato: 2026-09-08

## Natura del repository
API REST didattica in memoria per esercitare Spring Web MVC, dependency injection, validazione e costruzione corretta delle risposte HTTP.

## Stato osservato
- Java 21 e Spring Boot 4.1.
- GET lista, GET by id e POST implementati.
- Dati mantenuti in memoria.
- Controllo ISBN duplicato e validazione del modello.

## Limiti dichiarati
Nessuna persistenza, niente update/delete, error model globale o suite di test completa.

## Punto di ripresa
Il README elenca CRUD completo, DTO/error handling, JPA/MySQL e test come sviluppi possibili. Non sono passi attivi obbligatori finché questo esercizio non viene scelto esplicitamente per una nuova sessione.
